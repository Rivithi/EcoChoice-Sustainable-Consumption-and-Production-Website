🌍 EcoChoice – Sustainable Consumption & Production Website

EcoChoice is a group project website focused on **UN Sustainable Development Goal 12**: *Responsible Consumption and Production*.  
The site educates visitors about sustainable living, showcases global impact data, and provides resources for individuals, businesses, and governments to take action.

 🎯 Features

- **Home page** – hero section, mission statement, interactive content cards, global statistics.
- **Impact Data table** – responsive table with organization data (waste reduced, CO₂ saved, impact scores).
- **Content page** – in‑depth information about SDG 12 targets, solutions, and green technology.
- **Validation reports** – W3C validation screenshots for each page developed by Student 2.
- **Responsive design** – works on desktops, tablets, and mobile devices.
- **Accessibility** – semantic HTML, alt text for images, keyboard navigation, proper heading hierarchy.
