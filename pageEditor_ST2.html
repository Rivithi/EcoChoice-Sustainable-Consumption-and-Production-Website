Home Page validation report

Technical Description

The home page serves as the central hub of the website with the following features:

  • Responsive grid layout for SDG goal cards using CSS Grid
  • Interactive hover effects on navigation elements
  • Consistent header and footer structure across all pages
  • Global CSS styling for unified design
  • Hero section with gradient background
  • Content cards with hover animations

Key HTML/CSS Techniques

  • Used semantic HTML5 elements (header, nav, main, footer)
  • Implemented CSS Grid for the goal card layout
  • Created CSS variables for consistent theming
  • Added media queries for responsive design
  • Used flexbox for flexible component layouts

Accessibility

Accessibility features include:

  • Proper heading hierarchy (h1-h6)
  • Alt text for all images
  • Keyboard-navigable interface
  • Sufficient color contrast
  • Responsive design for all screen sizes

Table Page validation report

Technical Description

The table page features:

  • Interactive data table with hover effects
  • Responsive design for various screen sizes
  • Color-coded rows for better readability
  • Embedded links within table cells
  • Tooltips for additional information

Key HTML/CSS Techniques

  • Used complex table structure with rowspan/colspan
  • Implemented zebra striping with nth-child selectors
  • Added tooltips with CSS pseudo-elements
  • Styled with CSS transitions for interactive elements
  • Created responsive table behavior with overflow

Accessibility

Accessibility considerations:

  • Table captions and scope attributes
  • ARIA labels for interactive elements
  • Responsive table behavior
  • Keyboard navigation support
  • High contrast color scheme

Challenges and Lessons Learned

Key challenges included:

  • Creating a responsive table that works on mobile devices
  • Ensuring consistent styling across all pages
  • Implementing complex hover states without JavaScript
  • Balancing design aesthetics with accessibility requirements

Lessons learned:

  • Importance of semantic HTML for accessibility
  • Value of CSS variables for maintainable styling
  • Need for thorough cross-browser testing
  • Benefits of mobile-first design approach

Compliance

The pages comply with web standards by:

  • Using semantic HTML5 elements
  • Following WCAG 2.1 accessibility guidelines
  • Validating against W3C standards
  • Implementing responsive design principles
  • Adhering to the university's web publishing regulations
